# Todo App на Go

## Описание проекта

Проект создан для удобства постановки задач.
Он позволяет:
 - добавлять задачи;
 - удалять задачи;
 - устанавливать правило повторения задачи;
 - отмечать задачу как выполненную;
 - поиск задачи по контексту;
 - получать доступ к планировщику через пароль;

## Выполненные задания со звёздочкой:
 - Расширеная функциональность правил для повторения задач.
 - Поиск задачи по контексту и по дате.

## Инструкция по запуску кода локально
 1. Клонируйте репозиторий:
    ```git clone https://github.com/St-Ivanov/todo-app.git```
    ```cd todo-app```
 2. Установите зависимости:
    ```go mod tidy```
 3. Создайте переменную окружения с паролем, если хотите ограничить доступ:
    ```export TODO_PASSWORD=password```
 4. Запустите приложение:
    ```go run cmd/main.go```
 5. Откройте в бразере http://localhost:7540

## Тесты
 - Параметры тестов:
    1. Port - порт вебсервиса.
    2. DBFile - локальный путь до базы данных.
    3. FullNextDate - флаг, отвечающий за расширение правила повторения задач.
    4. Search - флаг, отвечающий за проверку поиска задач по контексту.
    5. Token - jwt токен, для проверки тестов для авторизированного пользователя.
 - Запуск тестов:
    ```go test ./tests```
## Инструкция по сборке и запуску через Docker
 1. Если хотите ограниченный доступ:
    - cоздайте файл .env;
    - поместите в него текст(где password это ваш пароль):
        `TODO_PASSWORD=password`
    - сохраните и закройте файл .env;
 2. Сборка образа:
    - выполните команду:
        `docker build -t todo-app .`
 3. Запуск контейнера:
    - выполните команду, если хотите неограниченый доступ:
        `docker run -p 7540:7540 todo-app:latest`
    - или выполните команду, если хотите ограниченый доступ:
        `docker run --env-file .env -p 7540:7540 todo-app:latest`
